# Bounded terrain feasibility and common assembly

Status: source design only. No global bake, accepted field, memory acceptance, release or new emitted packing is authorized by this document. Existing prototype publication guards remain active.

## Deterministic feasibility

The owner comfort limit is 0.5 m over a 32 m chord after removing only an affine horizontal-bend contribution. The current experiment's 0.45 m target is an internal margin, not an owner requirement. Its 0.75 m correction amplitude, 0.05/0.06 correction gradients and 32 m support are design choices, not geographic facts or owner limits. Physical grade, step, bridge, bore, contact and protection guards remain independent and unchanged.

The first question is feasibility at owner limit 0.5, not convergence toward the stronger internal 0.45 target. A deterministic min-max formulation minimizes t subject to `|sourceSag + chordTerms(delta)| <= t`, exact triangle-gradient disks, amplitude bounds and fixed protected nodes. A feasible point below 0.5 still needs a justified numerical margin, actual repack and geographic checks. A solver iteration limit is not an infeasibility certificate. Existing local `highs`, `glpsol` and linear/simplex package searches found no solver; no dependency or download has been added.

A verified finite necessary-bound certificate is available for Syntagma way23182769 at stations24 and40. Their source sags require a sum correction of at least 0.8790872012 m at owner limit0.5. Balanced transport of the exact lattice coefficients permits at most 0.8206721298 m under gradient0.05. Flow imbalance is 1.42e-14. Therefore that linear problem is infeasible, even after dropping support/protection restrictions. Necessary gradient is at least0.0535589774; this is a lower bound, not proof of a sufficient design or minimum of the complete problem. At internal target0.45 the same pair's necessary gradient is about0.05965. The source-only0.06 trial still fails the proxy, and does not establish infeasibility of owner0.5 feasibility. Future comparisons should distinguish these objectives explicitly.

`verifyTerrainComfortCertificate` derives coefficients from observations and recomputes transport costs from coordinates; it ignores claimed costs and rejects missing/unbalanced mass and invalid weights. It never accepts a comfort limit above0.5. Source and output packet hashes bind the observations. Proxy/repack residuals at the two certificate stations agree within one micrometre. Both rejected0.05 trials preserve the sampled Lycabettus summit and both sampled profile peaks exactly; the0.06 source model also preserves those peaks, with maximum east-west profile change0.015916m. These sampled source-model comparisons are not all-world geographic acceptance.

## Bounded storage before any larger stage

Do not retain decoded packets or a JavaScript object graph for all observations. The measured five-cell run had4,202 observations and peak RSS518,156,288 bytes; that includes the117MB JSON atlas and runtime/object overhead. This does not justify linear extrapolation to1,353 eligible cells.

Planned storage separates three bounded streams:

| Data | Proposed representation | Size basis, not measured implementation |
|---|---|---|
| Original sampled source field | Float32 tiles plus explicit validity/protection/lineage records | All1,748×4,225 samples:29,541,200 bytes, rather than117MB JSON |
| Canonical correction field | Float64 values with typed ownership/protection masks and deterministic shared-node ownership | Conservative1,353×4,225 upper bound:5,716,425 slots /45,731,400 value bytes; shared borders can reduce this |
| Observations | Per-cell binary records: seven Float64 coordinates/sag plus Uint32 edge and station references |64bytes/record. Merely applying the five-cell average gives1,137,062 observations /72,771,968 disk bytes; actual count must be measured by a bounded streaming pass |

Only one observation block and one decoded source packet remain resident while building observations. Terms are regenerated into typed node indices/coefficients for that block; no global Map of object records or decoded packs is retained. Corrections are shared globally, never independently solved per cell. An active typed cell/frontier queue propagates corrections and gradient constraints across canonical borders. Gradient projection checks both triangles at every touched node and a one-node neighbour halo; final passes include all changed/support nodes. Work is measured at small stages before scheduling larger CPU windows. The original basin manifest's largest decoded descriptor is9,901,576 bytes (cell-17,9; transient descriptor20,647,815), but descriptor reservations alone are not process-RSS measurements.

A conservative proposed single-process hard budget is1GiB RSS, with at least6GiB system MemAvailable before starting and checked between packets/solver sweeps. Packet decode, JSON/wire serialization, contact indexes, observations and solver scratch must be measured together; stop on pressure, never raise the budget silently. The typed fixed data estimates are under100MB, but this is only a forecast. Future bounded27/100-cell measurements must validate object elimination and CPU/pass cost before any global permission. Disk must remain below the repository85% hard stop, using one original cache and one derived packet set. No new whole-world scan is part of the current source-only stage.

Protected/source-missing nodes and every node shared with a protected owner remain fixed. The existing protected/outer transition is explicit; its residual comfort is reported separately rather than hidden. The original98 structure cells,225 authored Penteli and72 authored Megara remain protected from shape changes. New Ekali structure cells require the same explicit treatment. Final classification must use the exact combined inputs, including approved source-bound metadata repairs. Source heights are never interpolated across invalid atlas holes. Strict structural seam equality and actual contact checks against unchanged neighbours follow emitted packing, with exact portal/graph identity checks.

## Common derived assembly contract (pending implementation)

1. Authenticate each exact compressed input entry, source world/revision/cell and immutable upstream lineage before decode. Corrected-infill inputs and original inputs can have different authentic identities. A particular approved Megara graph-surface repair may change metadata hashes while preserving all authored physical bytes; use its explicit receipt, not a world-name fallback. Keep unchanged entries and original bytes untouched.
2. Apply only approved source-bound mutations in order. Terrain and building corrections precede final scenery clearance; marking conformance follows terrain. Prepare sealed bridge proofs against originals before mutation; rebuild guards only after compatible terrain/paint, preserving its physical fingerprints. Native `preserveOriginal` bypasses all mutation, identity reassignment and repacking.
3. For scenery, certify physical/contact/graph/parking/barrier/building invariance immediately before versus immediately after that mutation on the actual corrected base. Compare against the corrected input, not the original world before infill/terrain. Re-run full crown/obstacle clearance using the final physical base and preserve authored Vas Psychiko reservations/recipe.
4. After all applicable approved mutations, stamp a genuinely new derived world/revision into the actual packet metadata. Bind the recipe revision to every input SHA/identity, generator/helper/data hashes and stage ordering. Preserve each cell's original and immediate-input lineage in an audit receipt. Do not merely rewrite manifest descriptors while leaving source packet identities inconsistent.
5. Run authoritative packTiles in a single common-identity batch or strict per-cell identity groups. Ordinary packer gates and descriptors own all budgets/hashes. A mixed-world failure must never be bypassed. Verify decoded output identity against the new entry and source receipt, then assemble the flat manifest while unchanged entries retain exact original source identities.
6. Only final authenticated manifests/cells feed route/grid/width/contact/sidecar regeneration and eight spaced online-grid poses. No hand-edited geometry hashes or repeated old-world full exports. Parent owns both-bucket publication and release binding after all game/geographic/physical/source gates pass.
