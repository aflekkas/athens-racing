## Native Windows checks and limits

Node22.23.3, lockfile Electron44.4.5 and electron-builder26.15.6; source checkout disables autocrlf and preserves LF. NSIS is built natively with `--publish never`. The installer is silently installed outside the checkout, with fresh profiles and ASR_GAME_ROOT unset. Serial native GUI checks run six actual routes/free roam/pointer lock/Tow, Results PNG save/cancel/subframe denial, and two packaged clients with race/remote movement/reconnect/shutdown. All launches use `--mute-audio` plus persistent webContents muting.

A separate lifecycle probe uses genuine default `%APPDATA%/Athens Racing`, with no ASR_DESKTOP_USER_DATA override: write localStorage sentinel, uninstall, reinstall, verify retained sentinel, uninstall again. This tests actual default preferences rather than an arbitrary directory outside uninstaller scope. Native app metadata/name/version/audio state and observed WebGL renderer are recorded. No Windows acceptance has run yet; first-run uninstaller filename/exit behavior and desktop interactivity must be qualified, never silently skipped.

Existing harness `/tmp` default is handled by DESKTOP_TEMP_ROOT=RUNNER_TEMP. Linux flock/fuser browser-slot wrapper is not assumed on Windows; a named Windows mutex spans all serial GUI checks and is released in finally. Movement, network/security and persistence assertions are unchanged.

Ordinary hosted Windows does not establish consumer GPU/driver performance. A headed interactive desktop may be unavailable or pointer lock may fail; that blocks acceptance and requires an explicitly managed interactive Windows runner. One runner's two clients do not establish physical Mac↔Windows LAN, Windows Firewall discovery/prompts or hardware graphics. Unsigned status and SmartScreen/reputation/downloaded-quarantine behavior remain explicit separate limits. Existing Mac proof does not imply those pass.

Linux gates run from clean `git archive` of exact PR head SHA in RUNNER_TEMP, Linux x64 Node22.23.3/OpenSSL3.5.8: full no-retry npm test, physics, imports, syntax, events and ghosts. No deployment/cloud authentication exists in either job.
