# Greater Athens selector map

The Quick Race / Free Roam track picker is a full-page map of Attica (owner decision 2026-10-18: "the entire page should be the athens map, with this card hovering over"; no reset control). Everything is pre-rendered at build time from OSM and EU-DEM; the game makes no tile, API-key or geographic network request.

Runtime files, all generated by `tools/build-attica-map.py` (selector total about 342 KB, loaded only by the picker and cached for the session):

- `assets/maps/attica-land.webp`: 3000 × 1370 land texture (2 px per map unit, about 44 m). Soft multi-directional hillshade over a low-contrast slate elevation tint, with OSM built-up land as a slightly lifted fabric. The canvas clips it with the vector land polygons, so the coastline stays crisp at every zoom and DPR.
- `assets/maps/attica-sea.webp`: 750 × 343 sea texture. The DEM has no bathymetry, so the depth is a styling cue: a shallow band along the coast fading to deep water with distance from land.
- `assets/maps/attica-vectors.bin`: land rings, coastline and the road hierarchy (motorway, trunk, primary, secondary, tertiary and local streets), quantized to 1/40 map unit (about 2 m). The selector buckets lines into cells and strokes only what is on screen. The region view shows only the motorway/trunk network; the finer classes fade in as the camera closes on a track. Inside each track's corridor, the coarse overview roads are replaced by that track's full-resolution OSM `roadNetwork`, so close-ups line up with the race line.
- `src/attica-map-data.js`: projection (`MAP_VIEW`), asset paths, routes (path, pin, bounds, start/end, loop, length) and ranked, zoom-tiered labels (`MAP_LABELS`: OSM places and summits; `z` is the minimum zoom in screen px per map unit). Labels are DOM text at constant screen size; the selector places them greedily by rank and drops any that would cover a pin, a route, the header, the footer, the card or a higher-ranked label.
- `assets/maps/attica.svg`: a flattened composite of the same art, kept for the static menu backdrop.

Coverage: **23.00–24.50 E, 37.70–38.24 N**, Web Mercator, aspect preserved in all layouts. Megara Circuit is in West Attica.

## Sources and licences

- **OpenStreetMap contributors**, ODbL 1.0: https://www.openstreetmap.org/copyright . Coastlines, primary/secondary/tertiary roads and motorways, residential/commercial/industrial/retail landuse, places and peaks. Downloaded 2026-10-14 via `https://maps.mail.ru/osm/tools/overpass/api/interpreter` after the other mirrors timed out. Query region 37.74,23.47,38.23,24.10, clipped to the displayed extent. `source.json.gz` is the compact derived source snapshot, distributed under ODbL; projected coordinates in map units, rounded to 0.01 units, with 0.6-unit geometry simplification. No invented coastlines or terrain. The map art is an OSM Produced Work with visible linked attribution in the screen's bottom corner.
- Vector extension and land polygons: **OpenStreetMap / Protomaps**, ODbL; bounded HTTP Range requests to `https://build.protomaps.com/20261013.pmtiles`, 50 z11 tiles, retaining the original Athens roads/urban/places extract in the centre. Protomaps earth polygons at this zoom come from OSMCoastline: https://docs.protomaps.com/basemaps/layers . No runtime service dependency.
- Local race geometry: `data/map.json`, `data/maps/megara/map.json`, `data/maps/penteli/map.json`, `data/maps/psychiko/map.json`, OSM-derived WGS84 route positions and each track's OSM `roadNetwork` (highway ways around the route). Routes simplify by 0.06 map units (about 5 m); both endpoints are retained.
- Local elevation: `data/terrain.bin`, `data/maps/megara/terrain.bin`, `data/maps/penteli/terrain.bin`, `data/maps/psychiko/terrain.bin`, EU-DEM v1.1 via OpenTopoData at 10 m, blended into the relief wherever they cover it, feathered over 600 m. These grids also contain the game's road grading.
- Regional elevation: **Copernicus EU-DEM**, via Mapzen/AWS Terrain Tiles `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/12/{x}/{y}.png`. Tiles used: x2309–2326, y1576–1584 (fetched 2026-10-18). Produced using Copernicus data and information funded by the European Union — EU-DEM layers. EU-DEM's full, open and free access permits reproduction/adaptation with attribution: https://github.com/tilezen/joerd/blob/master/docs/attribution.md . The snapshot `dem.png` is a 1000 × 457 16-bit grid (metres + 100, about 130 m spacing), not the upstream full-resolution tiles. Without it the build falls back to the coarser 420-column grid inside `source.json.gz`. Hillshade uses a NW key light with W and N fills; no synthetic contours.

## Rebuild

Use a Python virtual environment with `numpy`, `Pillow`, `shapely` and `scipy`:

```sh
python3 -m venv .scratch/attica-map/venv
.scratch/attica-map/venv/bin/pip install numpy pillow shapely scipy
ATTICA_PYTHON=.scratch/attica-map/venv/bin/python node tools/build-attica-map.mjs
```

The default rebuild uses the committed snapshots plus shipped route, street and terrain data, without fetching. `--fetch-dem` refreshes `dem.png` from the z12 terrain tiles; `--fetch` refreshes the OSM surround and fallback DEM and additionally needs `pmtiles` and `mapbox-vector-tile`. Raw downloads cache under `.scratch/attica-map/` (override with `ATTICA_CACHE`); delete them after a refresh. The generator checks the size budget and verifies that Athens lies on land and a Saronic Gulf control point lies at sea before writing.

## Selector behaviour

Selecting a track (pin click or tap, ‹ ›, A/D or the arrow keys, gamepad left/right or LB/RB, a swipe on the card) flies the camera to frame that track's whole route in the free area beside the card (or above the phone bottom sheet). Long hops zoom out and back in (`flight()` in `src/map-select-camera.js`). The selected route is cased, glows faintly and traces itself in; the other tracks stay muted. Drag, wheel and pinch remain free map navigation, clamped to the art. Choosing a track always re-frames it, so there is no reset control. Reduced motion makes every camera change and the route trace immediate. All listeners and animation frames are released when the screen closes. Camera tests: `node --test tools/map-select-camera.test.mjs`. Owner guard: `tools/owner-locked-track-map.test.mjs`.
