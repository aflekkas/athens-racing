# Authored interiors, seated slightly high

Owner clarification: keep each car's distinct authored interior. The old 80% threshold and generic thin shell are superseded. The 55–78% window-opening band is a warning only; no model is stripped to satisfy it.

Runtime restores dashboard, console, cluster artwork, family trim, vents and controls from `6c89a4a^:src/cockpit.js`, keeping simplified geometry, current mirror/settings behavior, manufacturer atlas badges, curved telltales, no occupants/hands and the existing texture-rain/wiper system. Native passenger/commercial cabs use their own stations, wheel tilt and instruments; bikes retain their actual tank/fairing and bars. The default eye is slightly above the authored seat datum and five centimetres forward for cars (three centimetres for native cabs). Personal seat sliders remain ±8 cm per vehicle, with reset.

`EVERY-VEHICLE.md` reports every configuration's measured aperture, fully unobstructed view, road distance from both eye and bumper, instrument overlap, telltales, characters, before/after cockpit triangles and visible structure pixels. Source hashes and independent PNG recounts lock the all-70 fixture audit. The fixture's `before` phase is a legacy-eye diagnostic using restored geometry; **the actual released-before versus restored-after comparison is the Riviera world capture**, not that diagnostic.

World `before` routes only cockpit/camera modules to released baseline `85a37e6`. Both phases use the same current world, physics, start pose, FOV, environment time and weather. `SCENE-COUNTS.md` contains matched main-scene draw calls/triangles. No GPU/FPS claims. `pilot/` and `calibration/` are development evidence and are excluded from the final landing.

Proportion references inspected: [Porsche 911 cockpit](https://www.cars.com/research/porsche-911-2017/), [MINI cockpit](https://www.hcwc.club/cars/used/2020-MINI-3Door-218310), [Aventador SVJ cockpit](https://www.jutarnji.hr/autoklub/video/lamborghini-aventador-svj-lp-770-4-otrovno-zeleni-predator-pakleno-brz-na-cesti-na-stazi-jos-bolji-15368539), [Citaro driver station](https://www.daimlertruck.com/en/newsroom/presskit/driving-experience-2018-testing-the-new-features-of-city-buses-minibuses-and-touring-coaches-41872289). These informed dashboard depth, windshield/header proportions and family identity; the output remains blocky game geometry rather than photorealistic replicas. Downloaded reference photos are kept local and excluded from the landing.
